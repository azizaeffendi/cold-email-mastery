## 🎯 3 Framework Cold Email Terbaik

### FRAMEWORK 1: PAS (Problem-Agitate-Solution)
```
Subject: [Nama], masalah yang sering terjadi di [industri mereka]

Halo [Nama],

[PROBLEM] Banyak [jabatan] di [industri] yang saya ajak bicara
menghadapi [masalah spesifik yang relevan].

[AGITATE] Dan ini bukan hal kecil — [konsekuensi jika tidak diselesaikan].
Apalagi di [konteks saat ini: market condition, trend, dll].

[SOLUTION] Di [perusahaan saya], kami membantu [tipe klien] untuk
[solusi spesifik]. Salah satu klien kami, [nama/tipe perusahaan],
berhasil [hasil konkret dengan angka] dalam [timeframe].

Apakah ini relevan dengan situasi [perusahaan mereka]?
Kalau iya, boleh kita bicara 20 menit pekan ini?

[Nama Anda]
```

### FRAMEWORK 2: Before-After-Bridge
```
Subject: [Hasil yang ingin mereka capai]

[Nama],

BEFORE: [Describe situasi sekarang mereka — struggling]
AFTER:  [Describe situasi ideal yang mereka inginkan]
BRIDGE: [Perkenalkan bagaimana Anda menjadi jembatannya]

[Social proof: 1 kalimat hasil klien]

15 menit call pekan ini?
[Nama]
```

### FRAMEWORK 3: The Forwardable Email
```
Subject: Re: [topik relevan]

[Nama Manager],

Saya [nama], [jabatan] di [perusahaan].

Saya perhatikan [sesuatu spesifik tentang perusahaan mereka —
ekspansi, hiring, produk baru, award, dll].

[Berikan 1 insight yang valuable — sesuatu yang mereka tidak tahu]

Boleh saya tanyakan: apakah ada orang di tim Anda yang sebaiknya
saya ajak bicara tentang [topik]?

Terima kasih,
[Nama]

P.S. [Tambahkan context atau social proof singkat]
```

## ⚙️ Deliverability System

### Domain Warming Protocol
```
MINGGU 1:  10 email/hari (hanya ke kontak yang kenal)
MINGGU 2:  25 email/hari
MINGGU 3:  50 email/hari
MINGGU 4:  100 email/hari
MINGGU 5+: 200+ email/hari

SETUP WAJIB:
✅ SPF record
✅ DKIM signature
✅ DMARC policy
✅ Custom tracking domain
✅ Unsubscribe link
✅ Physical address
```

### Anti-Spam Checklist
```
❌ HINDARI dalam cold email:
- Kata: "gratis", "promo", "menang", "klik sekarang"
- ALL CAPS di subject line
- Terlalu banyak link (max 1-2)
- Image-heavy email (text-heavy lebih deliverable)
- Generic opening: "Semoga email ini menemukan Anda..."
- Multiple exclamation marks!!!

✅ LAKUKAN:
- Plain text atau minimal HTML
- Personalisasi baris pertama
- Satu CTA yang jelas
- Optimal length: 50-125 kata
- P.S. line (sering dibaca pertama)
```

## 🤖 AI Personalisasi di Skala

```
TRADITIONAL: Tulis email satu per satu = tidak scalable
AI-POWERED:  Semi-personalisasi untuk 1000 lead dalam 1 hari

WORKFLOW:
1. Export prospect list (nama, perusahaan, jabatan, URL LinkedIn)
2. AI scrape public info dari LinkedIn/website
3. AI generate personalized "first line" per prospect
4. Mail merge dengan template yang sudah proven

PROMPT untuk AI personalization:
"Dari informasi berikut tentang [Nama] yang bekerja di [Perusahaan]:
[info dari LinkedIn/website]

Tulis 1-2 kalimat pembuka yang sangat personal dan spesifik untuk
email cold outreach. Tidak boleh generik. Referensikan sesuatu yang
spesifik tentang mereka atau perusahaan mereka."
```
